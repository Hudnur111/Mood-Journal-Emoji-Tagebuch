# Mood-Journal / Emoji-Tagebuch

## Beschreibung
Das Mood-Journal ist eine Anwendung, die es Benutzern ermöglicht, ihre täglichen Emotionen und Stimmungen auf einfache und ansprechende Weise festzuhalten. Benutzer können Emojis auswählen, um ihre Gefühle auszudrücken, und Notizen hinzufügen, um ihre Gedanken zu dokumentieren. Diese Anwendung fördert das Bewusstsein für die eigene emotionale Gesundheit und hilft, Muster im emotionalen Wohlbefinden zu erkennen.

## Funktionen
- Auswahl von Emojis zur Darstellung der Stimmung
- Möglichkeit, Notizen zu den täglichen Einträgen hinzuzufügen
- Übersichtliche Darstellung der Einträge über einen bestimmten Zeitraum
- Benutzerfreundliche Oberfläche
